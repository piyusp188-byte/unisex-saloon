# Amarr Salon — Luxury Unisex Hair & Beauty Salon

Official website for **Amarr Salon**, a premier unisex salon located in Satellite, Ahmedabad. Built with a bespoke luxury design system featuring a deep noir and warm gold aesthetic, optimized background video hero, SEO structured data, and mobile-first responsive design.

---

## 🌟 Highlights

- **Hero Background Video**: Optimized WebM and MP4 video loop with instant poster fallback and smooth playback.
- **Luxury Aesthetic**: Custom tokens system featuring noir palette and warm metallic accents.
- **Mobile-First & Fully Responsive**: Tested across modern iOS Safari and Android Chrome viewports.
- **Local SEO & Schema.org**: Rich snippets for `HairSalon`, `AggregateRating`, `GeoCoordinates`, and breadcrumbs.
- **Performance Focused**: Pure HTML5, Vanilla CSS, and lightweight Vanilla JS with zero heavy frameworks.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via a local static HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node.js
npx serve .
```

Visit `http://localhost:3000` to view the website.
